# dsh-attendance

一个放在 DSH 侧栏里的考勤小工具。记下早上、下午和晚上的上下班时间，它会帮你算好每段、每天和每周的时长，也能翻看以前的记录。

## 怎么装

先把项目下载到本地：

```sh
git clone https://github.com/lxc0205/dsh-attendance.git
```

打开 DSH 的“插件”页面，添加刚下载的文件夹，启用后就能在左侧看到“考勤”。不需要额外安装依赖。

以后想更新，在项目文件夹里运行 `git pull`，再重启 DSH。

## 怎么用

1. 点一个日期，选早上、下午或晚上，点击时间块填写上下班时间，再点“保存时间”。
2. 填完整后，时长会自动算出来。上方的进度条显示本周累计，目标默认 40 小时，在“固定时间预设”里改，所有周共用。
3. 填错了，点时间旁的垃圾桶就能清空。想看以前的记录，可以切换周次，也可以直接选日期。
4. 查询区的“打开日志文件夹”会打开本机存储目录。考勤每天一份 JSON，固定预设和每周目标都放在设置文件里，方便自己查看和处理。

## 固定的时间，不用每天填

点右上角的“固定时间预设”，把固定的时间填进去就行。

比如每天早上都是 **09:00 上班**，就把这一项设成 09:00。以后它会直接显示这个时间，只需要填写下班时间。六个时间点都能单独设置；留空的才需要手填。

点“保存并同步今天”，今天已有的记录也会更新，以前的记录不会跟着变。下面填好时间并保存就会直接记录，不用再点一次确认；如果六个时间都预设好了，保存预设时就会记录今天。

## 用之前知道这几件事就够了

- 上下班都填好才计时；时间重叠或下班早于上班时会提示修改。暂时不支持跨夜班。
- 日期按北京时间算，一周从周一开始。查看历史时，上方进度条仍然显示本周。
- **记录保存在运行 DSH 的机器上。** 同一 Host 的浏览器可以共用文件，清理浏览器数据不会删除文件记录。升级后首次打开会迁移当前浏览器旧记录，原数据仍保留；冲突时以文件为准。
- 存储目录里，`records/日期.json` 是每日考勤，`settings.json` 保存固定预设和每周目标。保存不会额外生成 `.bak` 文件；需要留副本时，复制整个目录即可。手工编辑文件后点“重新读取”，尽量不要同时在界面保存。
- 时间块上的垃圾桶会直接清空已保存的时间；编辑框和预设里的垃圾桶只是清空输入，记得再点保存。
